# Campus Recall design context

The approved interface is a practical personal library with light neutral surfaces, dark text, system fonts and restrained blue accents. Desktop uses a navigation sidebar, content list and source inspector. Phones use a compact header, bottom navigation and full-screen source viewer. Search is prominent; saved and search-ready are different states.

Use rectangular buttons with corners at most 6 px, consistent labelled SVG icons, visible focus, 44 px main touch targets, phone inputs at least 16 px, safe areas and dynamic viewport units. Preserve pinch zoom and reduced-motion preferences. Motion is limited to useful feedback. Empty states explain the next real action. No fabricated library data.

No gradients, purple accents, pills, emoji icons, fake reviews or metrics, vague hero copy, AI stock imagery, generic marketing copy, authored em dashes, custom cursors or decorative scroll effects. Preserve user imports exactly.

Apply Emil Kowalski's Design Engineering and Mobile Native guidance where consistent with these constraints. Product flows must stay functional before model setup and offline. Settings and first-use information link Privacy and Terms. Review real behavior, typography, long content, keyboard navigation and narrow layouts, then record actual findings in a Before | After | Why table.
