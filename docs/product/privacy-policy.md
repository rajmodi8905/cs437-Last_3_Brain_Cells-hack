# Privacy Policy

Version 1.0 · Updated 23 October 2026

Campus Recall is a student project by Raj Modi, Chaitanya and Nakshatra. This policy describes the application in this repository. The team must review it again if hosting or data handling changes.

## Your library stays in this browser

Original files, notes, saved webpage text, titles, source URLs, extracted text, transcripts, embeddings and processing records are stored in IndexedDB on your device. Downloaded models and runtimes are stored in the browser's Cache Storage. No account is required. Libraries on different devices do not automatically synchronize.

Campus Recall does not upload library content, extracted data, embeddings or search queries for storage, analytics or inference. The application has no advertising or analytics. Local storage is not application-level encrypted. Someone with access to this browser profile may be able to access your library.

## Requests that need internet

Opening the hosted application sends an ordinary request to its static host. That host may keep technical access logs, such as IP address, browser information and request time. No hosted deployment or hosting provider is designated by this repository; review the actual host's policy when the team publishes a deployment.

Offline search setup explicitly downloads pinned open-source model files from Hugging Face and English OCR data from jsDelivr. Those providers and their delivery networks receive download requests. The app's own static host supplies the application and local runtime files. Downloads contain no library content or search query. Models run on your device.

Capturing a webpage sends a request to the URL you enter, without app-supplied credentials or a referring page. A website may receive your IP address and browser request information. Browser restrictions can prevent capture. You can paste text or import an HTML or PDF snapshot instead. Saved HTML is reduced to plain text and is never executed.

Opening an original website, the project repository or its issue tracker leaves the app and makes an ordinary request to that website. These external services have their own policies.

## Offline use and browser storage

After setup, core file processing, search and opening saved originals work without internet. The browser and operating system still control storage, permissions, eviction and backups. Campus Recall cannot prevent site data being cleared or determine whether the OS or browser backs up local data. Persistent storage requests are best-effort and do not replace backups.

## Delete, export and restore

Deleting an item removes its original, extracted segments, previews and queued processing records from this library. In-progress work cannot restore a deleted item. Deletion does not remove copies in earlier exports, other devices or OS/browser backups.

You can export originals and metadata in a manual, unencrypted ZIP. Keep it private. Models and embeddings are excluded. Restoring validates the archive before changing the library, skips matching content and queues restored originals for processing. Clearing this site's browser data removes the local library and cached assets.

## Contact and changes

Report privacy issues through the project repository's issue tracker: https://github.com/rajmodi8905/cs437-Last_3_Brain_Cells-hack/issues . Do not attach private documents to public issues. Future changes to data handling must be reflected here with a new version and update date.
