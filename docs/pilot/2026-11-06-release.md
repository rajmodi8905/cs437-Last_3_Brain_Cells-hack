# Azure pilot release — 6 November 2026

The separate Auto-sync pilot is live at https://campusrecall.indiasouthcentral.cloudapp.azure.com . It preserves the original coursework submission and repository main. The API and PWA share one HTTPS origin, with PostgreSQL on a separate managed data disk and originals/indexes/backups in private Azure Blob containers.

Cloud export and access end **6 December 2026 at 17:47 IST (12:17 UTC)**. Export originals and metadata through Settings before then. A persistent VM timer requests Azure deallocation at 12:17:11 UTC, limiting the compute window to 30 days from VM creation. Deallocation retains data and does not stop disk, public IP or Blob charges. Export/retention and final resource teardown remain separate operational steps; see the [runbook](deployment.md).

## Budget and remaining scope

The approved target is $80 for one month. The selected India South Central VM, two 32 GiB Standard SSD disks and static IPv4 have an indicative fixed retail cost of **$74.328 per 720 hours**, before storage operations, Blob capacity, traffic and applicable taxes. Monthly $80 budget alerts are configured; they are not a hard spending cap and reset across billing months. No extra $20 reserve has been treated as an automatic extension.

Blob/container soft delete is enabled for 14 days; versioning and previous-version lifecycle expiry are enabled. Recovery versions can persist for up to 28 days plus lifecycle processing delay. Database backups retain the newest 14 snapshots. Final resource teardown must account for the published export and recovery policy.

No physical-phone installation, real Google sign-in by a second person, hosted two-real-Google-browser model search, outside-group adoption count or completed end-of-pilot teardown is claimed. Local browser/model and synthetic hosted API results have the specific scopes above. Private operator logs, source/image archives, screenshots and credentials remain outside public documentation and are not automatically transferred to other machines.
