## Your material and account

You retain ownership of imported material. You are responsible for permission to store and use it, including material about other people. Auto-sync is restricted to verified IITGN Google Workspace accounts. Do not share your browser session or attempt to access someone else's vault.

Signing in does not upload your library. Explicitly including a library uploads originals, metadata, compatible embeddings and extracted content to your private Azure account vault. Authorized project operators can access this content; storage is not end-to-end encrypted. Read the Privacy Policy before including a library. Processing and search remain on your devices without cloud inference.

## Check original sources

Local models and similarity calculations retrieve saved originals without generating factual answers. OCR, transcripts and matching can be wrong or incomplete. Open the original to verify deadlines, instructions and other important details. No strong match does not prove you never saved the item. Only imported content is searchable.

English is the speech baseline. Video is sampled, so a brief scene may not be indexed. Supported formats and size limits appear on the Add screen. Cloud storage has an account quota; a full quota stops new uploads while originals remain on the importing device.

## Copies, export and deletion

Keep offline and Remove download control a device's downloaded cloud original. Pause stops background transfers on that device and leaves cloud data stored. Sign-out ends its cloud access; an optional checkbox removes retained account sync data locally. Deleting an account item and removing a cloud library are separate actions affecting active cloud data and other syncing devices. Recovery copies and database backups expire under the retention described in the Privacy Policy. Independent exports, browser or operating-system backups and copies outside the pilot are not removed.

Export cloud library downloads verified originals and metadata as unencrypted ZIP files. Large libraries may need several downloads. Keep exports private and test that important originals open. Restore each ZIP through Settings to create local copies for processing. Downloading an archive does not delete cloud data. Export requires sign-in, internet and an unchanged cloud library during the operation.

## Devices and other services

Browser storage is best-effort and can be cleared or evicted. Initial model setup needs internet and significant storage. Foreground processing, memory, browser support and compute capacity affect completion and speed. No paid inference API or personal inference API key is required.

Google sign-in, Microsoft Azure, model delivery services and external websites have their own terms and availability. Webpage capture can be blocked by browser rules; paste text or import an inert snapshot instead. Open-source component and model notices are recorded in THIRD_PARTY_NOTICES.md in the repository.
